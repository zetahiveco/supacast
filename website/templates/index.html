Supacast is a fast, keyboard-first launcher that lives in your menu bar. Search apps & files, manage todos, notes, clipboard history and calendar — and chat with an AI agent, all from one window.

Everything a launcher should do — and a bit more

🔍

App & file search

Instantly find macOS .app bundles and Windows Start Menu apps. Files come from Spotlight (mdfind) or a fast Windows folder scan.

⌨️

Global shortcut

Summon Supacast with ⌘ + ⇧ + Y (or Ctrl + ⇧ + Y on Windows). Change it any time in Settings.

✅

Todos & reminders

Capture tasks with due dates. A background loop notifies you right on time, even while Supacast stays hidden.

📝

Notes

Jot things down without leaving your keyboard, then find them again with instant search.

📋

Clipboard history

Everything you copy is saved and searchable. Paste old snippets with a couple of keystrokes.

📅

Calendar

See today's events and create new ones directly from the launcher — talks to the OS calendar natively.

🎙️

Dictate

Speak instead of typing. The transcript is pasted into whatever app had focus — or straight into the agent.

🤖

AI agent

A multi-turn agent with streamed output. Bring your own OpenAI-compatible API key and base URL.

🔄

Launch at login

Installed once, always there. Supacast registers itself to start automatically when your system boots.

Ready in one command

Install it, hit ⌘⇧Y, and never touch the mouse again.
